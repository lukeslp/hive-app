Idea Tiles 1.3.3 is a native macOS 26 app. No account or demo credentials are required for review.

On first launch, choose Tiles or Sphere. Both workspaces show the same local board: Tiles presents a flat hex canvas, while Sphere maps the board onto a rotatable 3D surface. Select a tile to expand it, mark key themes, and use the toolbar to switch workspaces. Artifact Studio can turn the board or a selection into a reviewable document, diagram, prototype, or file.

Generation is user-configured. On an eligible Apple Silicon Mac with Apple Intelligence enabled, choose Apple Foundation Models for on-device generation. The app can also use a loopback Ollama server, a supported provider credential supplied by the user, or an authorized Dreamer profile. Provider credentials are stored in Keychain, and the app identifies where board context will be sent before generation.

Boards and artifacts are stored locally. Sign-in is optional. Text artifacts can sync only after the user signs in; image files remain local unless the user explicitly selects them for upload. The app does not track users or use collected data for advertising.
